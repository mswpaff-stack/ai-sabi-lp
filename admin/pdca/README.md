## 概要

先に作成したAI-SABI管理画面モックをもとにした、新規PDCA管理画面。公開画面は静的ホスティングで、現在は5/1フォーム主配信結果、5/2休日A/B初速、5/3・5/4・5/7・5/8フォーム予約、5/8・5/11メール補完予約、フォーム主配信とメール補完の条件、グループ作成UIの注意点、既存ツール側予約への切替方針を表示する。

既存配信ツール側の画面は変更せず、以下の情報を新管理画面側で管理する想定。

- ABテスト設計
- 文面作成意図
- 配信済みキャンペーンと補正集計
- 結果分析
- 改善案
- テンプレート改善履歴
- セグメント選定理由

## 公開と保護について

2026-04-27時点では、ユーザー指示により公開URLの簡易ログインを外し、ID/PASSなしで閲覧できる仕様とする。

GitHub Pagesは公開静的ホスティングのため、機密情報、個人情報、既存配信ツールの認証情報、送信権限は置かない。クリック企業名、企業ID、送信先URLなど個社特定につながる情報も置かず、公開画面には集計値だけを反映する。

実運用で保護が必要になった場合は、Cloudflare Access、Vercel/Netlifyの認証、Basic認証付きサーバー、または新PDCA管理画面用バックエンドのセッション認証へ切り替える。

## 現在反映している実データ

- 既存LP選択肢: 160業種LPから `広告・デザイン向けAI活用伴走コンサル` を選択
- 現行テンプレート: `AI-SABI_Web制作_制作進行短縮_A_20260427`、`AI-SABI_Web制作_提案報告品質_B_20260427`
- 現行対象: `IT・サービス` DBの `広告・デザイン`
- 実配信結果: 静岡Aは96件指定、35件送信成功、トラッキング補正クリック3社。長野Bは77件指定、23件送信成功、トラッキング補正クリック2社
- 4/30地方6県結果: 実行候補301件、送信成功104件、失敗149件、スキップ48件、トラッキング補正クリック5社、クリックイベント8件
- 合計結果: 送信成功162件、トラッキング補正クリック10社、成功ベース補正クリック率6.2%
- 次回候補: 単純な10倍ではなく、爆速PDCAのために成功率34.6%前提で約3,000件の実行候補を目安にする
- グループ作成UI注意: フォーム主配信は `フォーム送信状態=未送信`、またはツール側重複除外を確認して `すべて` を使う。`メール送信状態` と `メール保有` は `すべて`
- メール補完: フォーム配信後に別グループを作り、`フォーム送信状態=失敗 + スキップ全部`、`メール保有=メールあり`、`メール送信状態=未送信` を標準にする。同時予約はせず、初期運用では1アカウント1日100件を上限にする
- A案: 制作進行短縮、B案: 提案・更新報告品質の安定
- LP誘導ルール: 本文に実URLを直書きせず、必ず `{{tracking_url}}` を使う
- 確定した件名・本文・作成名: `content/outreach-pdca/web-production-ad-design-small-lot-2026-04-26.md`

## UI調整メモ

- 自社用ツールのため、左下の相談・問い合わせ導線は削除済み
- ダッシュボードは累計KPI、ABテスト結果・考察、送信ガードまでに絞り、それ以降のPDCA計画、パイプライン、タスク、サマリー、リスク欄は表示しない
- UIアイコンは `assets/ai-sabi-pdca-icons-image2-v1.png` のimage-2生成PNGスプライトに統一
- トレンド矢印などの文字記号アイコンは使わず、生成PNGスプライトのアイコンを使う
- 主要PC幅では、KPI、ボタン、カード、サイドバーの文字はみ出しと、1文字だけの改行がないことを確認済み
- 長文のPDCA計画、キャンペーン一覧、結果比較、セグメント候補は、列幅の狭い表ではなくカード型リストで表示する
