# AI-SABI 問い合わせ営業PDCA 管理画面

作成日: 2026-04-25

## 概要

先に作成したAI-SABI管理画面モックをもとにした、新規PDCA管理画面の静的プロトタイプ。

既存配信ツール側の画面は変更せず、以下の情報を新管理画面側で管理する想定。

- ABテスト設計
- 文面作成意図
- 承認待ちキャンペーン
- 結果分析
- 改善案
- テンプレート改善履歴
- セグメント選定理由

## ファイル構成

- `index.html`: 画面本体
- `styles.css`: UIスタイル
- `data.js`: 既存配信ツールの確認結果を反映した静的データ
- `app.js`: 画面描画、ナビ切り替え、承認/送信デモ、同期デモ、Codex向け分析プロンプト生成
- `assets/ai-sabi-pdca-icons-image2-v1.png`: image-2生成アイコンシートを透過化した採用素材
- `assets/ai-sabi-pdca-icons-image2-v1-source.png`: 透過前の生成元

## 現在の連携状態

現時点ではデモ連携。

- `既存ツール数値を同期`: 最終同期時刻を擬似更新する
- `AI分析を実行`: 実データ、次回対象、LP選択、テンプレート作成ルールをまとめたCodex向けプロンプトを生成する
- `承認`: ステータスを承認済みにする
- `配信実行`: 本番送信ではなく、送信実行のデモ状態へ変更する

実データ連携は、別途バックエンドプロキシを作成し、既存配信ツールAPIと安全に接続する。

## 現在反映している実データ

- 既存LP選択肢: `Web制作向けLP`、`システム開発向けLP`
- 既存テンプレート: `WEB制作（テスト）`
- 既存キャンペーン: 鳥取県・徳島県の `IT・ソフトウェア` 向けWeb制作テスト
- 既存結果: 送信23件、クリック0件、LP閲覧2件、LINEクリック0件
- 次回対象: `IT・サービス` DBの `広告・デザイン`
- 初回候補: 鳥取県15件、徳島県15件
- LP誘導ルール: 本文に実URLを直書きせず、必ず `{{tracking_url}}` を使う

## UI調整メモ

- 自社用ツールのため、左下の相談・問い合わせ導線は削除済み
- UIアイコンは `assets/ai-sabi-pdca-icons-image2-v1.png` のimage-2生成PNGスプライトに統一
- トレンド矢印などの文字記号アイコンは使わず、生成PNGスプライトのアイコンを使う
- 主要PC幅では、KPI、ボタン、テーブル、サイドバーの文字はみ出しがないことを確認済み
